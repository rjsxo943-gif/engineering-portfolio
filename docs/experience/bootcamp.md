# Intel Edge AI DX / 피지컬 AI 부트캠프

**교육 실습 · 수강 중** · 2026.07 — 참여 중 · 공식 종료일 확인 필요

PLC를 중심으로 센서·공압·구동장치·로봇·통신을 학습했습니다. 강사 예제 기반 실습과 별도 팀 프로젝트를 구분합니다.

## 본인 역할

- GX Works2 래더, 순차제어, 타이머·카운터·인터록 학습·실습
- 센서, 공압 실린더, 컨베이어, 스토퍼, 서보·인버터 동작 원리 학습
- 뉴로메카 6축 로봇, Conty 3.3·Python 예제와 Pick & Place 티칭 실습
- PLC–로봇 Start/Done 핸드셰이크 및 CC-Link 연계 학습·실습

## 문제 해결과 확인 결과

### 동작 원리의 다른 구동 방식 적용

- **대응:** 기존 경험 기록에는 공압 회로를 분석해 동일 목적의 유압 회로를 구성한 학습이 기술되어 있습니다.
- **결과·현재 상태:** HMI·유압 세부 수행 범위와 결과는 추가 확인 대상으로 관리합니다.

## 팀·조직의 범위

교육 과정의 장치별 실습 경험입니다. 산업현장 운영·유지보수 경력이나 독자적인 통합 자동화 제품 개발 성과는 아닙니다.

## 범위와 한계

Factory I/O·OpenVINO는 적용 예정·구체 실습 미확인입니다. 공식 과정명·기간과 세부 장비 모델은 추가 확인이 필요합니다.

**사용·학습 기술:** GX Works2 · PLC · 공압 · Conty 3.3 · Python 실습

# AI 분실물 관제탑

**진행 중** · 2026.11.02 — 2026.11.13 (계획)

이미지 등록부터 후보 검색·직원 확인·로봇 반환까지 연결하는 실험적 팀 프로젝트. 2026.11.09 기준 비전·로봇 연계를 진행 중입니다.

## 본인 역할

- YOLO 탑뷰 검출 및 ArUco·호모그래피 기반 좌표 변환 담당
- 비전 특징 매칭 연계, SO-101 좌표 보정·집기 연계 담당
- 비전 어댑터·테스트 및 Qwen 연계 진단 수행

## 문제 해결과 확인 결과

### 관제탑의 보관 위치와 로봇 자세 명령 연결

- **대응:** 비전 좌표·로봇 좌표 보정과 관제탑 ↔ 로봇의 명령 연계를 진행하고 있습니다.
- **결과·현재 상태:** 최종 반환 서비스의 통합 완성·실증은 아직 완료로 확인되지 않았습니다.

## 팀·조직의 범위

팀 목표는 이미지 등록 → 특징/OCR 추출 → DB 후보 검색 → 직원 확인 → SO-101 로봇 반환입니다. Qwen3-VL, PaddleOCR, PostgreSQL/pgvector, LangGraph/MCP는 팀 구성 기술이며 모두 개인 독립 구현을 뜻하지 않습니다.

## 범위와 한계

2026.11.09 기준으로 비전–로봇 연계를 진행 중입니다. 최종 반환 서비스의 통합 완성·실증은 아직 완료되지 않았습니다.

# K2 스마트팩토리 팀 프로젝트

**완료 수준 확인 필요** · 2026.09 — 2026.10 · 교육 내 팀 프로젝트

K2 전차 모형의 조립·검사 공정을 나누어 구성하는 교육 프로젝트에서 비전·AI 검출 파트에 참여했습니다.

## 본인 역할

- 최종 검사 탑뷰 영상의 부품 누락·위치 확인을 위한 YOLO 활용 검토·개발 참여
- PLC/PC 역할과 장치 간 입출력·검사 신호 인터페이스 정의에 참여

## 문제 해결과 확인 결과

### 장치별 동작을 하나의 검사 흐름으로 연결

- **대응:** 공정 간 입력·출력 계약과 검사 신호를 구분하는 협업을 경험했습니다.
- **결과·현재 상태:** 개인 구현 범위와 최종 시연·검증 수준은 추가 확인이 필요합니다.

## 팀·조직의 범위

팀 공정 구상은 ST1 차체 조립, ST2 파워팩 검사, ST3 최종 검사로 나뉘며 PLC·로봇·컨베이어·HMI·카메라를 연계합니다. 전체 공정 구현을 개인 성과로 주장하지 않습니다.

## 범위와 한계

팀 프로젝트의 최종 완료 여부와 검출 성능은 확인 전입니다. 완성 공정이나 성능 수치로 표시하지 않습니다.

**사용·학습 기술:** YOLO · Vision AI · PLC / PC · 검사 인터페이스

# 전자공학과 학생회 총무부장

**완료** · 2025.01 — 2025.12

경상국립대학교 전자공학과 학생회에서 연간 약 2,200만 원 규모 예산과 8개 주요 행사의 재정 기록을 관리했습니다.

## 본인 역할

- 행사별 예산 편성 및 수입·지출·갹출비·환불 자료 정리
- 통장 거래 순서에 맞춘 영수증·이체 증빙 및 예외 거래 추가 자료 확보
- 총무부장 → 부학회장 → 학회장 → 대의원 결재·검토 절차 운영
- 감사자료집 원본 1권·복사본 7권 제작·제출

## 문제 해결과 확인 결과

### 예외 거래와 환불의 설명 가능성 확보

- **대응:** 일반 증빙만으로 부족한 거래에 추가 자료를 확보하고 승인 경로와 거래 순서를 기록했습니다.
- **결과·현재 상태:** 경험 기록상 중징계 없이 재정 운영을 마무리했습니다. 일부 양식 수정 요청이 있었고 감사 순위는 중위권이었습니다.

## 팀·조직의 범위

행사는 학생회 조직이 함께 운영했습니다. 본인 역할은 예산·수입·지출·증빙 관리이며, 결재는 부학회장·학회장·대의원과 분리해 운영했습니다.

## 범위와 한계

감사 과정에서 일부 양식 수정 요청이 있었고 평가 순위는 중위권이었습니다. 엑셀 통합관리·월별 마감·체크리스트는 향후 개선 계획입니다. 개인별 재무 증빙은 공개하지 않습니다.

**사용·학습 기술:** 예산 · 증빙 · 내부 통제 · 문서화 · 인수인계

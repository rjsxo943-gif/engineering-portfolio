- 프로필의 이름·전자공학 표기는 사용자 경력 PDF와 공개 마스터 초안에 근거합니다. 전화·이메일·연락처는 제공되지 않아 만들지 않았습니다.
- 기술 목록은 각 프로젝트의 태그·기여에 근거하며 직접 사용 / 진행 중 / 교육 실습 / 예정·미확인으로 구분했습니다. Qwen·OCR·DB·LangGraph는 팀 기술이며 개인 전부 구현으로 표시하지 않았습니다.
- 시계의 상세 원본이 없으므로 마스터 문안 이상으로 정량 성과를 확장하지 않았습니다.
- HMI·유압은 이전 경험 기록에 있으나 최신 직접 설명과 상세 검증은 추가 확인입니다. Factory I/O·OpenVINO를 사용 완료로 기재하지 않았습니다.
- RF 최종 런타임은 공개 최신 README의 Top5 vote·동일 주파수 재검증 구조를 우선했습니다. 경험 기록의 과거 temporal voting 실험과 구분합니다.
- RF 팀 인원은 확인 필요로 생략했습니다. 안테나 설계·제작은 팀 범위이며 개인 기여 목록에 넣지 않았습니다.
- 아성설비 근무 연도는 기록 충돌로 유보했습니다. K2 완료 수준과 분실물 최종 반환도 유보했습니다.
- 학생회 감사 중징계 없음은 원본 경험 기록의 진술입니다. 일부 양식 수정·중위권 평가를 함께 적고 무결점 감사로 과장하지 않았습니다. 향후 엑셀 관리 개선은 계획입니다.
- 공개 URL은 null이며 QR_PENDING입니다. URL·배포·스캔 완료를 주장하지 않았습니다.
